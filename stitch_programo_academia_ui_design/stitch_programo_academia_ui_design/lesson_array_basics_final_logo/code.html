Arrays: The Foundation

An array is the simplest and most widely used data structure. It operates on a fundamental premise: storing elements of the same type in contiguous memory locations. This contiguous nature is what gives arrays their superpower—constant time access to any element via its index.

memory

Contiguous Memory

Elements are placed back-to-back in RAM, eliminating overhead between items and allowing for cache-friendly iterations.

bolt

O(1) Access

Because the starting address is known, the address of any element can be mathematically calculated instantly using its index.

Initialization in C++

In modern C++, you can initialize arrays statically (fixed size at compile time) or dynamically. Below is an example of standard static initialization alongside std::array, which is the preferred modern approach for fixed-size collections.

main.cpp 
#include <iostream>
#include <array>

int main() {
    // 1. Traditional C-style array
    int rawArray[5] = {10, 20, 30, 40, 50};

    // 2. Modern C++ std::array (Preferred)
    std::array<int, 5> modernArray = {10, 20, 30, 40, 50};

    // Accessing via index (O(1) time complexity)
    std::cout << "First element: " << modernArray[0] << std::endl;
    
    return 0;
}
lightbulb

Code Intuition: Space vs Time

While arrays provide blazing fast O(1) read times, they are inflexible. If you need to add an element to an array that is already full, you must allocate a completely new, larger block of memory and copy all existing elements over. This makes insertion O(N) in the worst case.
